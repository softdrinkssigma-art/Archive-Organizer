# Archive-Organizer
special usb drive utility that takes files and zips them into organized 7z archives. Uses command prompt and powershell. only upports windows 10/11.
HOW TO USE:
run Launch.cmd
move the files you want to sort and compress into the "inbox" folder
in the app, press "process inbox"
wait for operations to finish
done!
HOW TO INSTALL:
download zip file
navigate to the install folder
run Install.cmd
select the drive you want to use (preferably removable ones) 
enjoy
NOTICES:
This utility was not built to run on FAT32 formatted drives.
if you click yes when it asks if you want to delete the files in the inbox, you cannot recover them.
This utility (as of 11/13/2026) is in version 1.0 and isn't fully bugtested.
yes, I did partly use ai to structure the project.
This utility uses the compression tool from the 7zip project.
