# Archive-Organizer
special usb drive utility that takes files and zips them into organized 7z archives. Uses command prompt and powershell. only upports windows 10/11.
HOW TO USE:
1.run Launch.cmd
2.move the files you want to sort and compress into the "inbox" folder
3.in the app, press "process inbox"
4.wait for operations to finish
5.done!
HOW TO INSTALL:
1.download zip file
2.navigate to the install folder
3.run Install.cmd
4.select the drive you want to use (preferably removable ones) 
5.enjoy
NOTICES:
1.This utility was not built to run on FAT32 formatted drives.
2.if you click yes when it asks if you want to delete the files in the inbox, you cannot recover them.
3.This utility (as of 11/13/2026) is in version 1.0 and isn't fully bugtested.
4.yes, I did partly use ai to structure the project.
5.This utility uses the compression tool from the 7zip project.
